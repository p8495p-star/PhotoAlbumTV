# Фото Альбом TV

Простое Android TV-приложение, которое открывает сайт фотоальбома в полноэкранном WebView.

Сайт: https://3.9807381.ru/

## Сборка
Проект собирается через GitHub Actions. APK создаётся как `app-debug.apk` и публикуется в Artifacts.

Проект не использует AndroidX AppCompat: приложение написано на стандартном Android Activity/WebView, чтобы минимизировать зависимости и избежать конфликтов Kotlin.
